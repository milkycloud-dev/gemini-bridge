# Changelog

## 1.0.0 (2026-09-25)

First tagged release of the state published on 2026-07-12.

- Backend: registration by app secret and hardware id, server tokens, queue until an admin assigns a Gemini key, Telegram alerts, streaming chat with uploads, IP and account bans, request stats.
- Client IPs logged correctly behind the proxy; uploads and history stored inside `DATA_DIR`.
- Flutter client: chat with Markdown, uploads, terms and privacy pages, mobile layout fixes.
- Admin panel for users, keys, history and bans.
- README in English and Russian, own icon, proprietary license text, release workflow.
